## 4️⃣ 주요 기능
사이트 링크랑 동작 되는 화면 gif 넣어볼 생각이에요
- [회원가입]()
  - 전화번호를 입력하고 인증번호를 받아 올바르게 입력하면 회원가입을 할 수 있다.
  - 회원가입을 하면서 관심분야를 선택하게 된다.
  - 초기 닉네임은 랜덤 닉네임을 부여 받는다. ex) 게으른 이무기
  - 만약 이미 가입되어 있다면 문구가 뜨고 로그인 페이지로 이동한다.

- [로그인]()
  - 전화번호를 입력하고 인증번호를 받아 올바르게 입력하면 로그인을 할 수 있다.

- [홈 화면]()
  - 화면을 옆으로 넘기거나 상단의 탭 메뉴를 클릭하여 각 카테고리의 게시판을 확인할 수 있다.
  - 게시글을 클릭하면 해당 게시글 화면으로 이동한다.
  - '+' 버튼을 누르면 탭 메뉴에 맞는 메뉴를 확인할 수 있다. -> 이거 되나요? 1

- [전체 게시판 목록]()
  - 하단 메뉴에서 '게시판'을 클릭하면 전체 게시판 목록을 확인할 수 있다.
  - 전체 게시판 목록에서 '주제' 버튼을 클릭하면 관심있는 주제를 선택하여 참여할 수 있다.
  - '같이해요' 버튼 클릭 시 '같이해요' 게시판으로 이동한다.
  - 화면 맨 위의 '화살표' 버튼 클릭 시 자기가 저장한 지역 목록을 볼 수 있다.

- [같이해요 목록]()
  - '같이해요' 카테고리의 게시글만 모아 볼 수 있다.
  - '+' 버튼 클릭 시 글쓰기 페이지로 이동한다.
  - '스터디', '오프라인' 등 각각의 버튼을 클릭하면 해당 특성의 모집 글을 조회할 수 있다.

- [같이해요 게시글 작성]()
  - 설명

- [기기거래 목록]()
  - PocketBase에서 데이터를 가져와 설계된 데이터 스키마를 기반으로 기기 거래 화면에 상품 항목을 렌더링 -> 이부분 사용자 관점으로 글 고치고 싶은데 윤경님 너무 열심히 써주셔서 못건드리겠어요
  - 상품 목록에서 거래 상태(거래 완료, 예약 중)와 지역, 날짜 정보를 확인 가능
  - 각 거래 항목에 대해 받은 총 좋아요 수를 표시
  - 탭 메뉴의 특정 탭(예: ‘선배님 스토리’, ‘기기 거래’, ‘질의응답’, ‘함께해요’)에 들어가야 하위 옵션 메뉴를 제공하는 플러스(+) 버튼 활성화
  - 플러스(+) 버튼을 누르면 해당 탭에서 사용할 수 있는 추가 옵션(헤드셋, 키보드, 마우스, 컴퓨터, 기타 등등)이 리스트 형태로 표시

- [기기거래 게시글]()
  - 여러 장의 사진이 등록된 경우, 좌우로 스와이프하여 상품 이미지를 확인 가능
  - 하트 아이콘 클릭 시 색상이 토글되며, 상태가 PocketBase 서버에 저장되어 새로고침하거나 페이지를 이동해도 좋아요 상태 유지
  - 상품의 거래 상태에 따라 버튼 색상이 동적으로 변경 (판매 완료 상태일 때 버튼이 ‘판매 완료’로 표시)
  - 페이지 왼쪽 상단의 ‘뒤로가기 아이콘’을 통해 직전 페이지로 이동, ‘홈 아이콘’을 클릭하면 기기 거래 목록 페이지로 이동
  - 오른쪽 상단의 링크 아이콘 클릭 시 현재 페이지 URL 복사 가능

- [Q&A 목록]()
  - 질의응답 게시판의 글만 모아서 볼 수 있다.
    
- [Q&A 게시글 작성]()
  - 제목과 본문 란에 각각 한 글자 이상 입력하면 완료 버튼이 활성화된다.
  - 완료 버튼을 누르면 DB에 저장되고 Q&A 페이지에서 확인할 수 있다.
    
- [Q&A 게시글]()
  - 게시글을 확인하고 댓글을 입력하거나 확인할 수 있다.
  - '스마일' 버튼을 누르면 이모지를 사용할 수 있다.

- [프로필]()
  -  PB 서버에 저장된 자신한테 달린 평가의 수를 이용해 열정 온도를 계산 
     -> (현재는 댓글 10개 당 온도 1이 오름) 
  - 온도를 게이지 형태로 화면에 표시
  - 로그인 시 PB 서버에 저장되어 있는 닉네임과 아이디 를 기반으로 사용
    ->로그인된 유저를 인식하여 UI 다르게 랜더링 
  - 받은 매너 평가 탭을 클릭하여 PB 내에 저장된 세부 평가 확인 가능 
  - 나의 프로필 버튼 탭을 클릭함으로서 프로필 디테일 페이지로 이동  
  - 팝업 창을 통한 기본 정보와 추가정보 입력 가능
